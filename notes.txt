DASHBOARD (Operator View)
├── Live feature values
├── Tolerance status (green/yellow/red)
├── Compensation status (active, accumulated offset)
├── History grid (last N parts)
└── Trigger capture / master buttons

MEASUREMENT CONFIG
├── Gauges
│   └── Channels
├── Features
│   ├── List features
│   ├── Add/Edit feature
│   │   ├── Name, type
│   │   ├── Inputs (A=Channel, B=Channel)
│   │   ├── Formula
│   │   └── Tolerance (nominal, upper, lower)
│   └── Delete feature

COMPENSATION CONFIG
├── List compensation rules
├── Add/Edit rule
│   ├── Feature (select)
│   ├── Controller (select)
│   ├── Tool number, offset register
│   ├── Trigger threshold
│   ├── Wear limit, max per cycle
│   └── Active toggle
└── Delete rule

CONTROLLER CONFIG
├── Machine
├── Controllers
│   ├── Connection (host, port, type)
│   ├── Signals (cycle complete, master)
│   └── Offset settings (resolution, method)
└── (future: tool life, redundant tools)

DATA LOG
├── Measurement log
├── Offset log
├── Cpk / SPC
└── Export
