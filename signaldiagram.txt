STEP 3: MEASUREMENT LAYER CAPTURES DATA
═══════════════════════════════════════════════════════════════════════════════

    ┌─────────────────────────────────────────────────────────────────────────┐
    │  MEASUREMENT LAYER                                                       │
    │                                                                          │
    │  Received: CYCLE_COMPLETE                                                │
    │                                                                          │
    │  1. Read N1700 gauge channels:                                           │
    │     ┌──────────────────────────────────────┐                             │
    │     │  CH0 (OD Left):   +0.003 mm          │                             │
    │     │  CH1 (OD Right):  +0.002 mm          │                             │
    │     └──────────────────────────────────────┘                             │
    │                                                                          │
    │  2. Evaluate Feature "Main OD":                                          │
    │     Formula: (A + B) / 2                                                 │
    │     A = CH0 = +0.003                                                     │
    │     B = CH1 = +0.002                                                     │
    │     Result: +0.0025 mm (deviation from nominal 25.000)                   │
    │                                                                          │
    │  3. Check tolerance:                                                     │
    │     Nominal: 25.000                                                      │
    │     Upper: +0.010                                                        │
    │     Lower: -0.010                                                        │
    │     Deviation +0.0025 is WITHIN tolerance → Status: OK                   │
    │                                                                          │
    │  4. Log Measurement record                                               │
    │                                                                          │
    │  5. Send to Compensation Layer:                                          │
    │     {feature: "Main OD", deviation: +0.0025, status: OK}                 │

    │  Deviation = +0.0055                                                     │
    │  Threshold = ±0.005                                                      │
    │                                                                          │
    │  |+0.0055| > 0.005 ?                                                     │
    │  YES → COMPENSATION TRIGGERED                                            │
    │                                                                          │
    │  CALCULATE OFFSET:                                                       │
    │  ┌────────────────────────────────────────────────────────────────────┐  │
    │  │  raw_offset = deviation × direction                                │  │
    │  │  raw_offset = +0.0055 × (-1) = -0.0055                             │  │
    │  │                                                                    │  │
    │  │  (negative = move tool CLOSER to cut more material)                │  │
    │  │                                                                    │  │
    │  │  SAFETY CHECKS:                                                    │  │
    │  │  • |−0.0055| ≤ max_per_cycle (0.010)? YES ✓                        │  │
    │  │  • accumulated + 0.0055 ≤ wear_limit (0.050)?                      │  │
    │  │    0.018 + 0.0055 = 0.0235 ≤ 0.050? YES ✓                          │  │
    │  │                                                                    │  │
    │  │  FINAL: offset_to_apply = -0.0055                                  │  │
    │  │         (rounded to controller resolution: -0.006)                 │  │
    │  └────────────────────────────────────────────────────────────────────┘  │
    │                                                                          │
    │  UPDATE STATE:                                                           │
    │  accumulated_offset: 0.018 → 0.024                                       │
    │  last_adjustment: -0.006                                                 │
    │                                                                          │
    │  Send to Controller: {tool: T01, register: D01, offset: -0.006}          │
    └─────────────────────────────────────────────────────────────────────────┘
